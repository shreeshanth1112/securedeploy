SECUREDEPLOY - RESTART CHECKLIST
Run this after every laptop restart or when you open a new terminal.
Never put passwords or tokens in this file.

=== 1. GO TO THE PROJECT AND TURN ON THE VENV (terminal 1) ===
sd
# If "sd" is not found, use the long form:
# cd ~/projects/securedeploy && source .venv/bin/activate
# Your prompt must start with (.venv). If not, the tools will be "command not found".

=== 2. CHECK WHERE YOU LEFT OFF ===
git status
git log --oneline -5
df -h /
# Keep at least 6G free. If it is lower, stop and investigate before any download or build.

=== 3. CHECK THE TOOLS ARE STILL THERE ===
python --version
pip-audit --version
bandit --version
gitleaks version
trivy --version
java -version
podman --version

=== 4. CHECK CONTAINERS AND IMAGES (read-only) ===
podman ps -a
podman images localhost/securedeploy
# The old container "demo" (Exited) must still be listed.

=== 5. START JENKINS (open a SECOND terminal tab with Ctrl+Shift+T) ===
cd ~/jenkins
JENKINS_HOME=$HOME/jenkins_home java -jar jenkins.war --httpListenAddress=127.0.0.1 --httpPort=8080
# Wait for "Jenkins is fully up and running", then open http://127.0.0.1:8080
# Stop Jenkins with Ctrl+C in that tab.
# Never paste or screenshot the admin password or any token.

=== 6. QUICK HEALTH CHECK OF THE CODE (terminal 1) ===
pytest -q
pip-audit -r requirements.txt
bandit -q -r app run.py
gitleaks git --redact .

=== 7. SCAN THE IMAGE (the /tmp files are deleted by restarts, so recreate the tar) ===
rm -f /tmp/securedeploy-dev.tar
podman save -o /tmp/securedeploy-dev.tar localhost/securedeploy:dev
trivy image --input /tmp/securedeploy-dev.tar --scanners vuln --severity HIGH,CRITICAL --ignore-unfixed --exit-code 1
echo "exit code: $?"

=== 8. KUBERNETES (Day 3 only) ===
minikube status
# Do not start, stop or delete the cluster until Day 3.

=== RULES ===
- Never run: podman system prune (it can remove images and volumes).
- Never delete the MySQL volume (student_db) or the "demo" container and image.
- Never use chmod 777.
- Never commit passwords, tokens or private keys.
- Scratch files in /tmp can disappear after a restart. That is normal.
